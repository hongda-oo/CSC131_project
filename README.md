# Fitness Booking App

## Overview
Fitness Booking App is a simple Java application created for the CSC131 Software Engineering project. The purpose of this project is to practice software engineering concepts such as object-oriented programming, Scrum, GitHub collaboration, UML diagrams, JUnit testing, and design patterns.

The application allows users to register and manage fitness training session bookings.

---

## Features

- User registration
- View training sessions
- Book training sessions
- Cancel bookings
- Manage coach schedules
- Simple console-based interface

---

## Technologies Used

- Java
- Eclipse IDE
- GitHub
- JUnit
- JIRA Scrum Board

---

## Project Structure

- `User.java`
  - Stores user information

- `Booking.java`
  - Stores booking information

- `Main.java`
  - Runs the application
